WinUI3 Compile Limitation

WinUI3 XAML compiler (XamlCompiler.exe, net472) exits with code 1 under dotnet build (Core MSBuild). This is not a XAML syntax issue but a known WinUI3 limitation - XAML pre-compilation requires Visual Studio's full MSBuild (not .NET Core version).

Verified parts:

  • NuGet restore OK (27s)
  • csproj syntax OK (RID fix + ApplicationDefinition fix)
  • XAML structure validation OK (15 controls, 65 instances, tag balanced)
  • XAML to HTML render OK (32KB screenshot)

Solution: Install VS 2022 Community (free) or Build Tools 2022 (with WinUI workload), then msbuild E2EApp.csproj /p:Platform=x64.
