## 前端 WebSocket 流程 vs 脚本直调流程分析

### 流程一：前端 → WebSocket → Agent
- 入口：`frontend/src/generateCode.ts` → WebSocket `ws://host/generate-code`
- 后端：`backend/routes/generate_code.py` 中间件管道（6 个 Middleware）
- 核心：`backend/agent/engine.py` AgentEngine 循环（最多 30 轮，9 个工具，流式推送）
- LLM：动态选模型（OpenAI/Anthropic/Gemini/Doubao），多 variant 并行
- 输出：WebSocket 流式推 `setCode`/`chunk` 到前端实时渲染
- 有预算控制（`costs/budget_checker.py`）、AgentRunRecorder 日志
- **关键问题**：系统提示让 LLM 调 `validate_code`，但该工具未注册到 Agent 工具列表

### 流程二：脚本直调 Ark API
- 入口：`backend/generate_5stacks.py` / `generate_5stacks_combined.py`
- 策略：1× Vision 分析截图 → 5× 纯文本调用生成 5 栈（26K vs 75K tokens）
- LLM：硬编码 `doubao-seed-2-1-turbo-260628`，httpx 直接 POST `/chat/completions`
- 输出：写文件（.kt/.xml/.qml/.html/.jsonl）+ JSON 报告
- 验证：离线 `validate_5stacks_v2.py` / `e2e_compile_verify.py`，不反馈到生成循环
- 无流式、无工具、无状态、无预算控制

### 核心差异
| 维度 | WebSocket | 脚本直调 |
|------|-----------|----------|
| LLM 调用 | Agent 循环 + 工具调用 | 直接 POST，无工具 |
| 流式 | 是 | 否 |
| 模型 | 动态选择多 provider | 硬编码 doubao |
| 多栈 | 单栈/请求 | 5 栈一次性 |
| 验证 | 无（工具未注册） | 离线验证 |
| 状态 | AgentFileState 多轮编辑 | 无状态单次生成 |
| 预算 | 有 | 无 |

## OCR PR 评论修复 (19:55)

### 问题
PR #7 的 OCR Bot 评论表显示 6 条 issue，但 Message 列全空。

### 根因（2 个）
1. **字段映射错误**：workflow 的 Python 脚本用了 `data.get("issues").get("file").get("message")`，但 OCR 实际 JSON schema 用的是 `data.get("comments").get("path").get("content")`
2. **Heredoc 缩进 bug**：`<<'PYEOF'` 的结束标记 `PYEOF` 前有 10 个空格（YAML 缩进），但 bash heredoc 终止符必须在行首 → "Post review summary" 步骤静默失败

### OCR 实际 JSON schema（从官方文档 + CSDN 示例验证）
```json
{
  "status": "success",
  "summary": { "files_reviewed": 6, "comments": 6, "total_tokens": 376139, ... },
  "tool_calls": { "total": N, "by_tool": { "code_comment": N, ... } },
  "comments": [
    { "path": "...", "start_line": N, "end_line": N,
      "severity": "critical|high|medium|low",
      "category": "bug|security|performance|...|other",
      "content": "审查意见文本" }
  ]
}
```

### 修复
- 提取 Python 解析器为独立文件 `scripts/parse_review.py`（避免 heredoc 缩进问题）
- 修正字段映射：`comments` → `path` / `content` / `severity` / `category`
- 表格新增 Category 和 Line 列
- 消息文本转义 `|` 和换行
- 用 `tool_calls` 替换 `stats`
- 加 debug echo 步骤打印 review.json keys
